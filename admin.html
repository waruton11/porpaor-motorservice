📤 Export HTML

กด Generate แล้วดาวน์โหลดไฟล์ index.html ไปแทนที่ไฟล์เดิมใน repo ได้เลย

ระบบจะรวมข้อมูลทั้งหมดที่แก้ไขใน Admin Panel แล้วสร้างไฟล์ index.html ใหม่ให้อัตโนมัติ

📊 อัพโหลดราคาจาก Excel

อัพโหลดไฟล์ Excel ราคารถจะอัพเดทบนเว็บไซต์ทันที — ไม่ต้องแก้ไขโค้ด

🛵 รถเล็ก (Honda: Wave, Click, PCX · Yamaha: Finn, Aerox, NMAX ฯลฯ)

ไฟล์: ราคาขายใหม่ล่าสุด.xlsx · ระบบเลือก sheet ตามแบรนด์ที่เลือกบนแถบบน — Honda = Sheet1 (โค้ด col A) · Yamaha = Sheet2 (โค้ด col B) · ราคาเงินสด col F

🏍️ Big Bike (Honda: Forza, ADV350, Rebel · Yamaha: MT-03, X-MAX, R3)

ไฟล์: ราคาขาย BIG Bike ใหม่ล่าสุด.xlsx · ระบบเลือก sheet ตามแบรนด์ที่เลือกบนแถบบน — Honda = sheet HONDA · Yamaha = sheet YAMAHA · โค้ด col B, ราคาขาย col E

ℹ️ ขั้นตอนการทำงาน
  1. เลือกไฟล์ Excel ให้ถูกประเภท (รถเล็ก / Big Bike)
  2. กดปุ่มอัพโหลด
  3. ระบบส่งไฟล์ไปที่ n8n → อ่านข้อมูล → อัพเดทฐานข้อมูล
  4. เว็บไซต์จะแสดงราคาใหม่ทันทีเมื่อ Refresh หน้า
